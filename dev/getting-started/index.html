Getting started

NLPDiagnostics supports Julia 1.10 and later. During the research-prototype phase, install it from its repository together with JuMP:

using Pkg
Pkg.add(url = "https://github.com/frederikgeth/NLPDiagnostics.jl")
Pkg.add("JuMP")

For work on a local checkout, activate your experiment environment and develop the package into it:

using Pkg
Pkg.activate("my-experiment")
Pkg.develop(path = "/path/to/NLPDiagnostics.jl")
Pkg.add("JuMP")

A minimal analysis

using JuMP, NLPDiagnostics

model = Model()
@variable(model, x >= 0)
@constraint(model, x <= 2)

report = analyze(model)
@assert report isa DiagnosticReport
length(report)
3

analyze takes a read-only snapshot through public MOI interfaces. It does not solve or modify the model. Display a concise terminal report:

print(text_report(report; minimum_severity = SeverityInfo))
NLPDiagnostics report with 3 findings
  [WARNING] underdetermined_equality_partition: The equality graph has an underdetermined Dulmage–Mendelsohn partition with 1 variables and 0 equations. (StructuralProof, confidence=certain)
  [WARNING] unmatched_structural_variables: 1 free variable is unmatched by the equality-constraint pattern. (StructuralProof, confidence=certain)
  [INFO] affine_implied_variable_bound: One-variable affine constraints imply variable 'x' lies in [0.0, 2.0]. (MathematicalProof, confidence=certain)

For programmatic work, keep the typed records:

records = report_data(report)
@assert records["findings"] isa Vector
sort!(collect(keys(records)))
5-element Vector{String}:
 "finding_code_counts"
 "finding_families"
 "findings"
 "metadata"
 "unavailable_reasons"

Choose evidence deliberately

Calling analyze(model) uses model-wide static and structural evidence. To ask questions about values, derivatives, rank, or conditioning, supply an explicit point or request analysis of complete model starts. Those conclusions are local to that point.

point = evaluation_point(model, [1.0]; label = "candidate A")
local_report = analyze(model; point = point)
@assert local_report.metadata[:evaluation_point_label] == "candidate A"
length(local_report)
4
