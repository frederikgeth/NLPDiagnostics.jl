Tutorial: your first diagnosis

This tutorial investigates a tiny inconsistent JuMP model. The aim is to learn the workflow: predict, observe, interpret, intervene, and compare.

Question and prediction

Can one scalar variable satisfy both $x \ge 10$ and $x \le 5$? Before running anything, predict that the feasible set is empty for a mathematical reason. No solver behaviour is needed to establish it.

Build and inspect

using JuMP, NLPDiagnostics

model = Model()
@variable(model, x)
@constraint(model, lower, x >= 10)
@constraint(model, upper, x <= 5)

report = analyze(model)
codes = Set(finding.code for finding in report)
@assert :inconsistent_affine_implied_variable_bounds in codes
print(text_report(report))
NLPDiagnostics report with 5 findings
  [ERROR] inconsistent_affine_implied_variable_bounds: One-variable affine constraints and declared bounds imply an empty interval [10.0, 5.0] for variable 'x'. (MathematicalProof, confidence=certain)
  [ERROR] inconsistent_opposing_affine_inequalities: Opposing parallel affine inequalities impose incompatible normalized bounds -5//1 <= a'x <= -10//1. (MathematicalProof, confidence=certain)
  [ERROR] inconsistent_reused_expression_sets: Constraints 1, 1 apply incompatible scalar sets to the same canonical expression. (MathematicalProof, confidence=certain)
  [WARNING] underdetermined_equality_partition: The equality graph has an underdetermined Dulmage–Mendelsohn partition with 1 variables and 0 equations. (StructuralProof, confidence=certain)
  [WARNING] unmatched_structural_variables: 1 free variable is unmatched by the equality-constraint pattern. (StructuralProof, confidence=certain)

The report may contain several views of the same underlying model. The one-variable bound analysis proves an empty implied interval. Structural findings may also observe that no equality determines x; that fact is true, but it is not the cause of this contradiction.

Inspect the specific finding:

contradiction = only(findings(
    report;
    code = :inconsistent_affine_implied_variable_bounds,
))
@assert contradiction.basis == MathematicalProof
(
    observation = contradiction.observation,
    affected_entities = contradiction.affected,
    suggested_actions = contradiction.suggested_actions,
)
(observation = "One-variable affine constraints and declared bounds imply an empty interval [10.0, 5.0] for variable 'x'.", affected_entities = EntityRef[EntityRef(:variable, 1, nothing, "x", nothing, nothing), EntityRef(:constraint, 1, nothing, "lower", "MathOptInterface.ScalarAffineFunction{Float64}", "MathOptInterface.GreaterThan{Float64}"), EntityRef(:constraint, 1, nothing, "upper", "MathOptInterface.ScalarAffineFunction{Float64}", "MathOptInterface.LessThan{Float64}")], suggested_actions = ["Inspect the one-variable affine rows, signs, constants, and variable-bound data."])

MathematicalProof means the conclusion follows from the supported represented model data. It does not mean that source-data intent, units, or the physical meaning of the bound has been verified.

Make one intervention

Suppose the upper bound was a transcription error and the intended value was

  1. Rebuild that single input and rerun the same analysis:
repaired = Model()
@variable(repaired, y)
@constraint(repaired, y >= 10)
@constraint(repaired, y <= 15)

repaired_report = analyze(repaired)
@assert isempty(findings(repaired_report; severity = SeverityError))
print(text_report(repaired_report))
NLPDiagnostics report with 4 findings
  2 informational findings hidden by default
  INFO summary: `affine_implied_variable_bound` (1 occurrence)
  INFO summary: `reused_constraint_expression` (1 occurrence)
  [WARNING] underdetermined_equality_partition: The equality graph has an underdetermined Dulmage–Mendelsohn partition with 1 variables and 0 equations. (StructuralProof, confidence=certain)
  [WARNING] unmatched_structural_variables: 1 free variable is unmatched by the equality-constraint pattern. (StructuralProof, confidence=certain)

The error disappears as predicted. This is evidence that the contradictory bounds caused the static inconsistency. In a real investigation, justify the new bound from an authoritative source record; the diagnostic cannot decide which bound reflects the intended system.

Exercise

Replace the upper bound with x <= 10. Predict the outcome before running the analysis. Is the variable infeasible, merely bounded, or fixed? Inspect the finding basis and affected entities, then explain what the result does and does not establish about a larger model containing this variable.
