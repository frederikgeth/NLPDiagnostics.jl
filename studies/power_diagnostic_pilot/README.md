# Engineer study preparation package

**Prepared, not run.** No incident records or reviewers are available yet.
No contacts have been made and no participant data exist.

The [machine-checked intake and freeze workflow](intake/README.md) is ready for
independently prepared incident records. It verifies declared evidence hashes,
baseline completeness, private-answer separation, and workflow/material changes.
It refuses empty collections and does not establish authenticity or run a study.

1. Read `protocol.md` for the proposed pilot and freeze requirements.
2. Use `incident_template.json` to record each independently documented incident
   and permission/source/evidence references. It is an empty template, not a case.
3. Build equal-information baseline/report packages and freeze assignment and
   scoring before sessions. The template does not itself establish permission.
4. Use `reviewer_form.md` and `adjudication_form.md` during a future study.

The software's frozen synthetic evaluations are not substitutes for these records.
Do not report improved repair time or engineer accuracy before an actual study.
