# Reviewer form — one incident

Participant code: ____  Incident code: ____  Presentation order: ____

Start time: ____  First diagnosis submitted: ____  Final submission: ____
Interruption or time-limit outcome: ____

1. What, if anything, is wrong? Identify the component, input, or equation.
2. Which supplied evidence supports that conclusion? What remains uncertain?
3. What change, if any, would you propose, and why should it address the cause?
4. Confidence in the diagnosis (0–100): ____
5. What additional evidence would you need before acting?
6. Did any wording, missing analysis, or status label confuse you?

Do not apply changes to an operational system. A proposed change is recorded for
assessment only. A justified abstention is preferable to an unsupported diagnosis.
